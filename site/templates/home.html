这个站用到的 Go 能力

🛣️

net/http 路由

标准库自带路由和中间件写法，不需要任何 Web 框架就能撑起一个站点。

🧩

html/template

服务端渲染 HTML，自动做上下文转义，天然防 XSS，首屏也没有白屏等待。

📦

embed 内嵌资源

模板和 CSS 打包进可执行文件，部署时只有一个二进制，没有「文件漏传」问题。

🔌

JSON 接口

encoding/json 直接编码结构体，/api/info 与 /api/health 开箱可用。

自己试试这些接口

① 请求信息检测

打开 /request，Go 会把你的 IP、UA、请求头整理成表格给你看（Cookie 和 Authorization 已过滤）。

② POST 回显接口

服务端解析 JSON 并回显，用来确认后端真的在工作：

curl -X POST {{if .Host}}https://{{.Host}}{{end}}/api/echo \
  -H "Content-Type: application/json" \
  -d "{\"hello\":\"world\"}"

PowerShell 里用：
Invoke-RestMethod -Method Post -Uri https://你的域名/api/echo -ContentType application/json -Body '{"hello":"world"}'

准备好上线了吗

本地已经能跑，部署到 Vercel 只需要三条命令；也可以编译成单个二进制丢到自己的服务器上。

go run .          # 本地预览 http://127.0.0.1:8080
npx vercel        # 首次部署
npx vercel --prod # 正式发布
